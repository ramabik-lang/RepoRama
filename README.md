# Ramabik

Repo utama untuk menyimpan file LIPITA, sertifikat, dokumentasi sekolah, dan aset digital lain.

## 📁 Struktur
| Folder | Isi |
|--------|-----|
| `lipita/` | Data Excel LIPITA |
| `sertifikat/` | Sertifikat siswa |
| `documents/` | PDF, dokumen sekolah |
| `images/` | Chart, flowchart, screenshot |
| `scripts/` | Python, macro, tools |

## 🚀 Cara Pakai
- **Upload:** Add file → Upload files → Commit changes
- **Download:** Klik file → Download / Raw
- **Clone:** `git clone https://github.com/ramabik-lang/Ramabik.git`

## 📋 Catatan
- Gunakan branch `main` untuk file final
- Gunakan branch `testing` untuk percobaan
